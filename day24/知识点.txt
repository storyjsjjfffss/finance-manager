1. 核心知识点
一、 继承（Inheritance）的本质
在实际开发中，不同业务对象往往存在大量共有属性与方法（例如：经理、程序员都是“员工”；战士、法师都是“英雄”）。

父类（基类 / 超类）：提取所有子类的通用属性与通用行为。

子类（派生类）：自动继承父类的一切公开属性和方法，同时可以定义自己专属的属性与方法。

Python
class Parent:
    pass

class Child(Parent):  # 括号内写入父类名即表示继承
    pass

二、 super() 与父类构造器复用
子类在拥有自己独有属性的同时，通常也需要继承父类的属性初始化。

super().__init__(...)：代表调用直接父类的构造方法，把公共属性的初始化委托给父类处理，避免在每个子类中重复编写 self.name = name。

三、 方法重写（Method Overriding）
如果父类提供的方法无法满足子类的特殊业务需求，子类可以定义一个与父类同名的方法。

当子类实例调用该方法时，Python 会优先执行子类重写后的版本。

四、 类型检查函数
isinstance(obj, ClassName)：检查某个对象是否属于指定类（或其子类）。

issubclass(SubClass, SuperClass)：检查一个类是否是另一个类的子类。
